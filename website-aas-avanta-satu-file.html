    Teori AAS

    Atom bebas di dalam nyala menyerap cahaya dari lampu katoda berongga pada panjang gelombang khasnya. Makin banyak atom, makin besar serapannya. Untuk Ca dipakai 422,7 nm.

    Hukum Lambert-Beer: A = ε · b · c. Absorbansi (A) berbanding lurus dengan konsentrasi (c), sehingga kurva kalibrasi berbentuk garis lurus.

    Alur alat: sampel dihisap → nebulizer → spray chamber → burner → nyala → monokromator → detektor (PMT) → komputer.
